# Humani (휴머나이) · humanai.io.kr

한국어 AI 휴머나이징 전문 서비스 사이트입니다. AI 작성률을 무료로 검사하고, AI 탐지기에 걸리는 문장만 골라 사람 문장으로 바꿉니다.

- `docs/` : GitHub Pages로 배포되는 사이트(정적 파일, 사용자 도메인 humanai.io.kr)
- `_src/build.py` · `_src/pages.py` : 사이트를 만드는 생성기(`python3 _src/build.py` 를 실행하면 `docs/` 를 다시 만듭니다)
- `_src/shop/render.py` : 성균관컨설팅(아임웹) 상품 이미지 만들기
